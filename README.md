# どばどばWDWツアー

2027年5月のフロリダ・ディズニー旅行に向けた、夫婦2人用の作戦帳アプリ（PWA）。

- 公開URL: https://pyonkichi777.github.io/wdw-futari/
- iPhoneでは Safari で開き、「共有」→「ホーム画面に追加」でアプリのように使えます

## いまできること（Phase 1）
- **図鑑**: 4パークの主なアトラクション（身長制限・激しさ・優先パスの種類など）
- **投票**: 2人がそれぞれ「絶対乗る／乗りたい／どちらでも／乗らない」をつける。相手の回答は、自分が全部答えると見える
- **合意リスト**: 投票から S（何があっても乗る）／A（なるべく）／B（乗れたら）を作り、2人で並べ替えて確定

## 開発
```
npm ci
npm run dev     # 開発サーバー
npm test        # テスト
npm run build   # 型チェック＋本番ビルド
```
